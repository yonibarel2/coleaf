# CoLeaf – Docs

These files are the only source of truth. To work on a doc elsewhere (e.g. as an online artifact), copy it out, copy the result back here, then delete the copy.

The core three build on each other: product.md (what and why) shapes architecture.md (how), and plan.md (when, in what order) follows from both.

| File | What it is | Read it when |
| --- | --- | --- |
| [product.md](product.md) | What CoLeaf is, why us, product decisions, ideas | Before deciding what to build |
| [architecture.md](architecture.md) | How it's built: stack, structure, decisions | Before changing how something works |
| [plan.md](plan.md) | Status, stages, work plan, technical decisions | Before starting any work |
| [codemap.md](codemap.md) | Where things are in the code, one line per module | Looking for code; update it every slice |
| [editor/markdown.md](editor/markdown.md) | Every Markdown syntax and what CoLeaf does with it | Touching editing, saving or round-trip tests |
| [ui/](ui/) | Mockup images | Building or changing the UI |
| [market/competitors.md](market/competitors.md) | Competitors and the gaps CoLeaf can fill | Positioning, features, pricing |
| [market/marketing.md](market/marketing.md) | Launch ideas | Planning the launch |

Rules for AI agents: [AGENTS.md](../AGENTS.md).
